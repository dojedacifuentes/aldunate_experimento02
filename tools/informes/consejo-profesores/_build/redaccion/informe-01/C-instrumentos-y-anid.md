# Anexo C. Instrumentos formales y proyectos de investigación

## 1. Instrumentos que acreditan capacidades formalizadas

Una capacidad se considera formalizada cuando existe un documento citable que la sostiene: un acto administrativo, un acuerdo de un órgano colegiado, un código de asignatura con créditos, un código de proyecto adjudicado por un fondo público, un registro de propiedad intelectual, un convenio firmado o una unidad listada en el organigrama publicado.
