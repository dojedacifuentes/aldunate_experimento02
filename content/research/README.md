# Investigación profunda

Esta carpeta reúne evidencia que podrá alimentar:
- informes;
- visualizaciones;
- landing académica;
- papers;
- experimentos;
- materiales docentes.

## Archivos
- `source-registry.csv`: inventario de fuentes.
- `evidence-matrix.csv`: afirmaciones y evidencia.
- `research-notes-template.md`: plantilla de notas.

Principio:
**fuente -> evidencia -> dato -> visualización -> conclusión**.
